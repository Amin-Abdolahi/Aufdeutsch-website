تو باید یک فایل JSON معتبر برای WordTree سایت AUF Deutsch تولید کنی.

هدف:
- زبان هدف فعلی این نسخه از WordTree همیشه آلمانی است.
- موضوع کاملاً قابل انتخاب است؛ مثلاً رستوران، سفر، فرودگاه، پزشکی، خرید، دانشگاه، کار، زندگی روزمره یا هر موضوع دیگری.
- تعداد کلمات دقیقاً همان عددی باشد که کاربر درخواست می‌کند.
- سطح دقیقاً همان سطح درخواستی باشد.
- ترجمه‌های فارسی و انگلیسی هر دو باید وجود داشته باشند، چون نسخه فعلی سایت هر دو فیلد را در ساختار ورودی خود می‌شناسد.

فرمت خروجی دقیقاً باید مطابق این ساختار باشد:

{
  "version": "1.0",
  "language": "de",
  "words": [
    {
      "de": "کلمه آلمانی با حرف تعریف برای اسم‌ها",
      "fa": "ترجمه فارسی",
      "en": "ترجمه انگلیسی",
      "category": "noun | verb | adjective | phrase | number | color",
      "level": "A1 | A2 | B1 | B2 | C1",
      "noun": {
        "article": "der | die | das",
        "plural": "حالت جمع"
      },
      "verb": {
        "praeteritum": "گذشته ساده",
        "perfekt": "شکل Perfekt",
        "auxiliary": "haben | sein"
      },
      "pronunciation": {
        "persian": "تلفظ فارسی‌نویسی"
      },
      "example": {
        "de": "جمله نمونه آلمانی",
        "translations": {
          "fa": "ترجمه فارسی جمله",
          "en": "ترجمه انگلیسی جمله",
          "de": "خود جمله آلمانی"
        }
      }
    }
  ]
}

قوانین الزامی:
1. خروجی باید یک JSON معتبر باشد.
2. فقط JSON خام را خروجی بده؛ هیچ توضیح، مقدمه، نتیجه‌گیری، Markdown یا code fence اضافه نکن.
3. تعداد عناصر آرایه words باید دقیقاً برابر با تعداد درخواستی باشد.
4. مقدار language همیشه "de" باشد.
5. هر کلمه باید فیلدهای de، fa، category و level را داشته باشد.
6. fa و en برای همه کلمات اجباری هستند.
7. category فقط یکی از این مقادیر باشد: noun, verb, adjective, phrase, number, color.
8. level باید دقیقاً یکی از A1, A2, B1, B2, C1 باشد و همه کلمات همان سطح درخواستی را داشته باشند.
9. اگر category برابر noun است، noun.article و noun.plural هر دو اجباری هستند و article فقط می‌تواند der، die یا das باشد.
10. اگر category برابر verb است، verb.praeteritum، verb.perfekt و verb.auxiliary هر سه اجباری هستند و auxiliary فقط می‌تواند haben یا sein باشد.
11. برای categoryهای دیگر، فیلد noun یا verb را اضافه نکن.
12. pronunciation.persian را برای هر کلمه با تلفظ طبیعی و قابل‌فهم فارسی بنویس.
13. example.de و هر دو ترجمه fa و en را برای هر کلمه ارائه کن.
14. example.translations.de باید همان جمله آلمانی example.de باشد.
15. کلمات تکراری نباشند.
16. کلمات باید واقعاً با موضوع و سطح درخواستی مرتبط باشند؛ کلمات نامرتبط را فقط برای پر کردن تعداد اضافه نکن.
17. اگر برای یک کلمه اطلاعاتی مثل جمع یا صرف فعل مطمئن نیستی، آن کلمه را با یک مورد مطمئن جایگزین کن.
18. خروجی نهایی باید مستقیماً قابل Paste در بخش Import JSON بازی باشد.

- زبان ترجمه اصلی: [فارسی/انگلیسی]
- توضیحات اضافی: [در صورت وجود]
